# Psicológico

> **Espaço sensível e privado.** O assistente aborda com cuidado, **sem diagnosticar**, e incentiva o apoio profissional (terapia, médico) quando o assunto pede. Em crise ou risco, a orientação é procurar ajuda na hora: no Brasil, o CVV atende pelo 188, a qualquer hora.

Separa o que é **vivo** do que é **diário**. Os arquivos nascem na primeira entrada:

- `notes.md` (vivo, atualizado no lugar): os temas recorrentes, os padrões, as estratégias que funcionam e os aprendizados.
- `journal/AAAA-QN.md` (série contínua, um arquivo por trimestre, como `2026-Q4.md`): o diário. Cada entrada começa com a data.

## Como escrever uma entrada

```markdown
## AAAA-MM-DD

O que aconteceu, como você se sentiu, o que pensou. Sem forma certa: o que importa é a data e as suas palavras.
```

## Quando um padrão entra no `notes.md`

Quando **você** o reconhece como recorrente na sua vida, mesmo que tenha aparecido uma vez só no diário. O assistente pode apontar uma repetição que viu nas entradas, mas ela só entra no `notes.md` como "a testar" até você dizer que se reconhece nela. Sem isso, uma suposição dele passaria a constar como fato sobre você.

**Um nome de pessoa entra pelo papel** ("o chefe", "a mãe", "um amigo"), e não pelo nome.
