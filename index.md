# Índice: o que ler, e quando

Abra só o que casa com a tarefa. Cada pasta tem um `README.md` ou um `index.md` com o detalhe.

| Arquivo ou pasta | O que tem | Ler quando |
|---|---|---|
| [`README.md`](./README.md) | o repositório privado antes do dado pessoal, os primeiros passos (quem programa e quem não programa), as skills e o que cada uma roda | ao chegar; ao ligar uma skill nova; ao configurar uma chave |
| [`context/sobre-mim.md`](./context/sobre-mim.md) | quem usa o assistente, como prefere receber informação e a voz ao escrever conteúdo | ao escrever qualquer coisa em nome da pessoa; ao decidir o formato de uma resposta longa |
| [`context/publico.md`](./context/publico.md) | para quem você fala, as objeções e as restrições | ao apurar um tema (`story-angle`) e ao fazer uma peça (`piece-creation`) |
| [`context/brand/`](./context/brand/README.md) | a marca: logos, paleta, letra, fotos | ao montar uma peça ou um material fora de uma série |
| [`finance/`](./finance/README.md) | as finanças pessoais (e as do negócio, quando a empresa faturar): o método e o roteiro do que preencher | ao lançar uma receita ou despesa; ao fechar um mês; ao falar de dívida |
| [`health/`](./health/README.md) | treino, alimentação, exames e o psicológico: as naturezas de arquivo e o padrão de ciclos | ao registrar um treino, uma refeição, um exame ou uma entrada de diário; ao montar um plano |
| [`maps/`](./maps/README.md) | os mapas de autoconhecimento e de direção (guias em `maps/guides/`, o quadro local em `maps/board/`) | ao fazer ou revisar um mapa; ao adotar um plano ou um OKR |
| [`decisions/`](./decisions/README.md) | as decisões de método, com o porquê de cada uma | quando uma skill cita a decisão como porquê; antes de mudar uma regra |
| [`assistant/`](./assistant/README.md) | o espelho opcional da memória e da configuração do Claude Code (desligado; só em repositório privado) | ao ligar o espelho; ao restaurar a memória numa máquina nova |
| [`knowledge/index.md`](./knowledge/index.md) | a base de conhecimento por área, com as fontes | antes de pesquisar (o que já se sabe); ao escrever com lastro; nos rituais de ingestão (`knowledge/README.md`) |
| [`knowledge/sources/README.md`](./knowledge/sources/README.md) | a régua de fonte e de conteúdo de terceiro (o que entra inteiro, o que entra só em ficha) | ao registrar uma fonte; antes de guardar texto de terceiro |
| [`marketing/social-media/`](./marketing/social-media/README.md) | as ideias, as séries, os carrosséis avulsos, os Stories, as rubricas e o banco de imagens | ao registrar uma ideia; ao fazer, revisar ou exportar uma peça |
| [`marketing/licoes.md`](./marketing/licoes.md) | as lições das peças | antes de fazer uma peça; ao fechar uma |
| [`.claude/skills/`](./.claude/skills/) | as skills, cada uma com `SKILL.md`, `references/projeto.md` e `licoes.md` | ao usar, criar ou editar uma skill (lições primeiro) |
| [`.claude/skills/project-kit/`](./.claude/skills/project-kit/SKILL.md) | o kit de projeto novo: a discussão inicial, os modelos, a montagem e o GitHub; o que é da sua conta no `references/projeto.md` | ao criar um projeto de software novo; ao mudar um modelo do kit (com `knowledge/software-engineering/` e `decisions/kit-de-projeto-novo.md`) |
| [`.claude/skills/licoes-gerais.md`](./.claude/skills/licoes-gerais.md) | as lições que valem para várias skills | antes de criar, editar ou testar qualquer skill |
| [`AGENTS.md`](./AGENTS.md) | aponta o Codex CLI para o `CLAUDE.md`, a fonte única | ao usar o Codex direto no projeto |
| [`scripts/`](./scripts/) | `confere_ambiente.py` (o que falta configurar), `confere_dados.py` (dado pessoal e de terceiro, e se o repositório com registro pessoal é privado), `confere_links.py` (os links e as duas cópias dos agentes), `empacota_skills.py` (ZIP para a conta), `medir_disparo.py` (o disparo de uma skill), `jev/` (o cliente do Jev, opcional) | ao configurar; antes de commitar material de fora; ao levar skills à conta; ao mexer na `description` de uma skill |
