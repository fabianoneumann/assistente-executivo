# Carrosséis avulsos

Os carrosséis fora de série, uma pasta por post: `AAAA-MM-DD_<tema>/`, com o mesmo conteúdo da pasta de uma peça de série (o roteiro, o `slides.html`, os `assets/`, a `legenda.md` e o `refinamentos.md`). Sem série, a identidade visual de cada avulso é escolhida na primeira mesa da peça, pela skill `piece-creation`.
