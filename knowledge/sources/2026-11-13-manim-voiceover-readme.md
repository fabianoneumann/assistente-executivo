# manim-voiceover: a voz e o tempo por palavra dentro da cena do Manim

Ficha em palavras próprias; o texto integral não vem neste repositório e se lê na url do frontmatter.

**Proveniência.** README do repositório. Baixado em 2026-11-13 pela API do GitHub (ou do servidor indicado). Estado do repositório pela API do GitHub em 2026-11-13: 327 estrelas, criado em 2022-10-13, último push em 2026-06-15, 60 issues e PRs abertos, última release v0.4.0 2026-06-14T16:19:41Z, licença reconhecida pelo GitHub: MIT.

**Em uma frase:** o plugin põe a narração dentro da cena do Manim, gravada pelo microfone durante o render ou por TTS, e dispara a animação na palavra, com o Whisper.

| Ponto | O que o texto diz |
|---|---|
| Gravar a própria voz | por uma interface de linha de comando, durante o render |
| Tempo por palavra | animação disparada numa palavra da narração, também nas gravações, pelo Whisper da OpenAI |
| TTS citados | Azure, gTTS, pyttsx3, além da gravação |

**Lacuna:** o texto não dá requisito de máquina nem fala de português.
