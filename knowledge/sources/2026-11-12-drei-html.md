# drei: o componente `<Html>`, que prende HTML a um objeto da cena

Ficha em palavras próprias; o texto integral não vem neste repositório e se lê na url do frontmatter.

**Proveniência.** Arquivo `docs/misc/html.mdx` do repositório pmndrs/drei (ramo `master`), https://github.com/pmndrs/drei/blob/master/docs/misc/html.mdx, baixado em 2026-11-12. Lido inteiro. O componente é do drei, a coleção de ajudantes do React Three Fiber; o código-fonte é `src/web/Html.tsx`, e a página o marca como "Dom only".

## O que o componente faz e as opções

| Opção | O que faz, pela página |
|---|---|
| (o componente) | prende conteúdo HTML a qualquer objeto da cena e o projeta automaticamente para onde o objeto está |
| `center` | desloca −50% / −50% em CSS (ignorado no modo transform) |
| `distanceFactor` | se definido, escala os filhos por esse fator e pela distância numa câmera perspectiva, ou pelo zoom numa ortográfica |
| `zIndexRange` | faixa da ordem de sobreposição (padrão `[16777271, 0]`) |
| `transform` | aplica transformações `matrix3d`; o tamanho passa a depender da posição em relação à câmera, do FOV e do `distanceFactor` |
| `sprite` | desenha como sprite, só no modo transform |
| `calculatePosition` | troca a função de posição (ignorado no modo transform) |
| `occlude` | esconde o HTML atrás da geometria (toda a cena ou objetos dados); `onOcclude` avisa quando muda, para animar a transição |
| `occlude="blending"` | oclusão "real", como se o HTML fizesse parte da cena 3D; aceita material (`meshPhysicalMaterial` com `DoubleSide`) e sombras, que só funcionam com material próprio |
| `prepend`, `fullscreen`, `portal`, `as`, `wrapperClass` | atrás do canvas, tela cheia a partir do canto, contêiner de destino, elemento e classe do invólucro |

## Ressalvas da página

- No modo `blending`, só elementos retangulares se escondem certo; para outra forma, trocar a geometria de apoio pela opção `geometry`.
- No modo transform, o HTML pode sair borrado em alguns aparelhos e navegadores (issue #859 do repositório); a página sugere diminuir o pai e aumentar o filho para atenuar.
- Um exemplo da página dá o "número mágico" em que o HTML no modo transform fica do tamanho de um HTML comum: objeto na origem, `distanceFactor` 10, câmera perspectiva em (0, 0, 2,45) e FOV 75.

## Citações

- "Allows you to tie HTML content to any object of your scene."
- "Html 'blending' mode only correctly occludes rectangular HTML elements by default."

## Lacuna

A página não fala de render quadro a quadro, de captura de vídeo nem de quanto custa ter muitos `<Html>` na cena; não diz se o conteúdo HTML entra numa captura feita só do canvas.
