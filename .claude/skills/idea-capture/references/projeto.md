# O que é deste projeto

O arquivo da skill com o que muda de projeto para projeto. O `SKILL.md` guarda o método; aqui ficam as pastas e as decisões que valem neste repositório. Quem instala a skill noutro projeto troca só este arquivo.

## Onde escrever

| O quê | Onde |
|---|---|
| Ideia de conteúdo (o padrão) | `marketing/social-media/ideas/<tema-em-kebab-case>.md` |
| Decisão de estrutura ou de negócio, inequivocamente | `decisions/<tópico>.md` (um arquivo por tópico, com o porquê) |

Na menor dúvida, é `marketing/social-media/ideas/`.

## As decisões que esta skill segue

- `decisions/artefatos-e-estagio.md`: a linha de abertura `**Nota:**` e a ausência do campo `estagio` na ideia crua (o campo nasce em `pauta`, gravado pela `story-angle`).
- `decisions/licoes-das-skills.md`: o formato e os estados do `licoes.md`.

## As outras skills

| Skill | Para quê |
|---|---|
| `story-angle` | desenvolver a ideia registrada até a pauta (esta skill nunca faz isso) |
| `research` | pesquisar (esta skill nunca chama) |

## O que este projeto precisa ter

- A pasta `marketing/social-media/ideas/` (nasce com o primeiro registro, se não existir).
