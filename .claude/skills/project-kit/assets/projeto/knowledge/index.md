# Índice da base

Abrir só o que o "ler quando" casa com a tarefa. A regra de operação está no `README.md`.

| Página | Ler quando |
|---|---|
| `README.md` | Antes de escrever na base, ou para saber onde mora o quê |
| `arquitetura.md` | Antes de mexer na forma do sistema, nas fronteiras entre as partes ou numa integração |
| `plano.md` | Para saber os arcos, as grandes entregas e a ordem sugerida, ou ao abrir uma milestone |
| `processo.md` | Ao escrever ou trabalhar uma issue, abrir um PR, ou mudar o fluxo |
| `metadados.md` | Ao abrir uma issue e preencher a lateral, ou para achar o que pegar agora |
| `travas.md` | Quando uma trava recusar um comando, ou ao mudar o fluxo, o CI ou um hook |
| `versao-e-dependencias.md` | Ao cortar uma versão, ou quando chegar um PR do Dependabot |
| `decisions/` | Antes de decidir algo de arquitetura ou de ferramental; o `000-modelo.md` é o modelo do ADR |
| `log.md` | Para saber o que aconteceu e quando (as últimas entradas, pelo fim) |
